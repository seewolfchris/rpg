# Contributing

C76-RPG ist proprietaere Software.

## Contribution-Modell
- Externe Contributions sind nicht als offenes Standardmodell vorgesehen.
- Beitraege erfolgen nur nach vorheriger Absprache mit dem Projektverantwortlichen.
- Anfragen zur Abstimmung oder Lizenzierung: admin@c76.org

## Pull Requests
- Unabgestimmte PRs koennen ohne Review geschlossen werden.
- Bei abgestimmten Aenderungen gelten die bestehenden Qualitaetsgates (Tests, Build, Analyse).

## Rechtehinweis
- Die Sichtbarkeit eines Repositories auf GitHub ist keine freie Nutzungserlaubnis.
- Beitraege oder Review-Kommentare duerfen nicht als Erlaubnis zur Weiterverwendung, Weitergabe, Fork-Nutzung, kommerziellen Nutzung oder Erstellung abgeleiteter Werke verstanden werden.
- Massgeblich ist die proprietaere LICENSE im Repository.
